퐁퐁폰 관리자

GitHub 토큰으로 들어가면 내폰사기 상품, 내폰팔기 매입시세, 알뜰폰 · 선불폰 요금제를 바로 고칠 수 있습니다. 저장하면 1~2분 뒤 사이트에 반영됩니다.

저장소 설정 (보통 바꿀 필요 없음)
토큰 발급 방법 (처음 한 번만)
  1. GitHub 로그인 후 주소창에 github.com/settings/tokens 입력
  2. Fine-grained tokens 탭에서 Generate new token 클릭 (이름은 "퐁퐁폰 관리자" 등 자유)
  3. Repository access 에서 Only select repositories 를 고르고 pongpongphone 만 체크
  4. Permissions 의 Repository permissions 에서 Contents 를 Read and write 로 변경
  5. 만들어진 토큰을 복사해 위 칸에 붙여넣기 (토큰은 다시 볼 수 없으니 안전한 곳에 보관)

토큰은 이 브라우저 안에만 저장되고 GitHub 외의 다른 곳으로는 보내지 않습니다. 공용 PC에서는 저장 체크를 끄고 쓰세요.
